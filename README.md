# 空谷回响 HollowEcho

一款参考《空洞骑士》(Hollow Knight) 玩法设计的 2D 横板类银河恶魔城原型，使用 **Godot 4.7.2 (GDScript)** 开发。所有画面均由代码实时绘制，无外部图片素材。

## 运行

用 Godot 4.7.2（标准版，非 .NET 版）打开本目录下的 `project.godot`，或命令行：

```bash
godot --path .
```

游戏主场景为 `res://scenes/main.tscn`。

## 操作

| 按键 | 功能 |
|------|------|
| A / D 或 ← / → | 移动 |
| 空格 | 跳跃（长按跳得更高） |
| J / Z | 挥钉；配合 W / 空中 S 可上劈 / 下劈 |
| K / X | 冲刺（获得「风纹披风」后） |
| L / C | 施放法术（消耗 33 灵魂） |
| 长按 F | 聚集灵魂治疗（消耗 33 灵魂 / 1 面具） |
| E | 互动（长椅、路牌） |
| Tab | 地图 |
| Esc | 暂停 |
| R | 结局后重新开始 |

## 已实现内容

- **移动**：加速/减速、可变跳跃高度、土狼时间、跳跃缓冲、冲刺、蹬墙滑行与蹬墙跳、二段跳、下劈弹跳。
- **战斗**：四方向骨钉攻击、受击无敌帧与击退、灵魂积累、聚集回血、法术弹、屏幕震动、命中火花。
- **银河城结构**：7 个互连房间（遗忘十字路 → 苔藓甬道 → 沉眠圣所 / 回响深井 → 石壁回廊 → 王座前厅 → 破碎王座），能力门会阻挡未获得对应遗物的玩家。
- **遗物**：风纹披风（冲刺）、螳螂爪（蹬墙）、王翼（二段跳）、面具碎片（生命上限）。
- **魂系要素**：长椅存档/回血、死亡掉落全部吉欧并在原地留下阴影、击败阴影取回吉欧、再次死亡则永久丢失。
- **敌人与 Boss**：爬虫、飞蛾、镰刀守卫；Boss「残破守卫」拥有跳跃砸地冲击波、冲锋、50% 血量二阶段，击败后进入结局。
- **UI**：面具血量、灵魂球、吉欧计数、房间名横幅、提示/拾取 toast、Boss 血条、地图、暂停、标题与结局画面（中文 SystemFont）。
