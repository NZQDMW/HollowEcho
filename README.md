# 空谷回响 HollowEcho

一款参考《空洞骑士》(Hollow Knight) 玩法设计的 2D 横板类银河恶魔城原型，使用 **Godot 4.7.2 (GDScript)** 开发。所有画面均由代码实时绘制，无外部图片素材。

## 运行

用 Godot 4.7.2（标准版，非 .NET 版）打开本目录下的 `project.godot`，或命令行：

```bash
godot --path .
```

游戏主场景为 `res://scenes/main.tscn`。

## 操作

| 按键 | 功能 |
|------|------|
| A / D 或 ← / → | 移动 |
| 空格 | 跳跃（长按跳得更高） |
| J / Z | 挥钉；配合 W / 空中 S 可上劈 / 下劈 |
| K / X | 冲刺（获得「风纹披风」后） |
| L / C | 施放法术（消耗 33 灵魂） |
| 长按 F | 聚集灵魂治疗（消耗 33 灵魂 / 1 面具） |
| E | 互动（长椅、路牌、NPC 交谈） |
| Tab | 地图 |
| Esc | 暂停 / 关闭对话 |
| R | 结局后重新开始 |

商店内：W / S 选择商品，E 购买，Esc 离开。

## 已实现内容

- **移动**：加速/减速、可变跳跃高度、土狼时间、跳跃缓冲、冲刺、蹬墙滑行与蹬墙跳、二段跳、下劈弹跳。
- **战斗**：四方向骨钉攻击、受击无敌帧与击退、灵魂积累、聚集回血、法术弹、屏幕震动、命中火花。
- **银河城结构**：10 个互连房间（遗忘十字路 → 苔藓甬道 → 沉眠圣所 / 回响深井 → 石壁回廊 → 王座前厅 → 破碎王座；沉眠圣所 → 静默集市 → 钟鸣洞窟 → 回响之厅），能力门与钥匙门会阻挡未满足条件的玩家。
- **遗物**：风纹披风（冲刺）、螳螂爪（蹬墙）、王翼（二段跳）、面具碎片（生命上限）、锈蚀钥匙（开启集市深处的门）、回响之心（可选 Boss 奖励）。
- **魂系要素**：长椅存档/回血、死亡掉落全部吉欧并在原地留下阴影、击败阴影取回吉欧、再次死亡则永久丢失。
- **深渊救援**：回响深井与钟鸣洞窟的裂隙会把坠入者送回岸边并扣除 1 格生命，避免掉入深坑后卡死。
- **NPC 与商店**：静默集市的「灰烬商人·墨」出售面具碎片、灵魂容器、骨钉磨石与锈蚀钥匙，「记录者·铃」提供多页世界观对话。吉欧至此有了实际用途。
- **可选支线**：静默集市 →（锈蚀钥匙）→ 钟鸣洞窟 → 回响之厅，挑战可选 Boss「钟鸣守卫」（48 血，二阶段），获胜获得「回响之心」（生命上限 +1、骨钉伤害 +1、灵魂上限 +33）。击败后结局追加一行台词。
- **敌人与 Boss**：爬虫、飞蛾、镰刀守卫、吐酸者（远程酸液）、跃虫（扑跳）；主 Boss「残破守卫」拥有跳跃砸地冲击波、冲锋、50% 血量二阶段，击败后进入结局。
- **UI**：面具血量、灵魂球、吉欧计数、房间名横幅、提示/拾取 toast、Boss 血条、对话/商店面板、地图（10 房间 + 图例 + 探索计数）、暂停、标题与结局画面（中文 SystemFont）。

## 测试与演示

- 基础演示录像：`screenshots/result/1/video.mp4`（30 秒，30 FPS，附原始 `frame*.png` 帧序列）。
- 内容分镜：`screenshots/result/content/shot_*.png`（静默集市、商店、记录者、钟鸣洞窟、面具碎片、钟鸣守卫、地图、回响之心奖励）。
- 系统回归：`test/test_systems.gd`（遗物拾取、长椅、死亡/阴影回收、Boss/结局断言）。
- 内容回归：`test/test_content.gd`（NPC/商店购买与售罄、钥匙开门、新房间、面具碎片、可选 Boss 奖励与不再刷新）。
- 演示脚本：`test/presentation.gd`（SceneTree 驱动，基础流程）；`test/presentation_content.tscn` + `test/presentation_content_node.gd`（内容分镜 / 长镜头）。
- 分镜捕获（每个场景独立短录制，结果稳定）：

```bash
godot --path . --write-movie screenshots/moments/shop/frame.png \
  --fixed-fps 30 --quit-after 200 res://test/capture_moment.tscn -- --moment=shop
```

`--moment` 可选：market / shop / lore / cavern / mask / boss / map / reward。

> 本机 Godot 4.7.2 下用 `--script` 配合 `--write-movie` 会输出透明帧，长镜头演示请改用 `.tscn` 驱动场景（`test/presentation_content.tscn`），并用 `--quit-after` 结束录制，不要从驱动脚本里调用 `get_tree().quit()`。
