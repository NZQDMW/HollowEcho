- PowerShell Start-Process for Godot; quote the exe path. `--headless` works for validation but renders nothing; omit headless for capture.
- **SceneTree `--script` compile order:** the main-loop script compiles before autoload singletons and before global classes are available to it. Do NOT reference `Game` directly or reference a global class whose script uses `Game` (e.g. `Boss`) from a test script — use `root.get_node_or_null("Game")` and `node.get_script() == load("res://scripts/boss.gd")` instead. Otherwise: "Identifier not found: Game" / "Failed to compile depended scripts".
- **Movie maker frame count:** the recorded movie length equals script frames only if the script runs at the same cadence; keep `--quit-after` >= script quit frame and verify `"N frames at 30 FPS"` in stdout. A partial run leaves stale PNGs from earlier attempts in the output folder — always delete the result folder first.
- **ffmpeg encoding:** the pip `imageio-ffmpeg` Windows build has no glob support. Encode with `-start_number 0 -i frame%08d.png`, not `-pattern_type glob`.
- **One-way ledges:** CollisionShape2D `one_way_collision = true` on ledges prevents the player's head colliding with platform undersides (an issue that silently stops horizontal movement).
- **Pickup persistence:** rooms are rebuilt on every load; store taken pickups in `Game.taken_pickups` (key `room:x:y`) and skip already-collected relics/mask shards, otherwise relic labels/pickups respawn after room reload.
- **Dash tuning:** dash 1050 px/s × 0.2 s with 450 px/s exit speed crosses the 340 px r4 gap; earlier 920×0.16 fell just short and the player got stuck against the right platform side.
- Final proof bundle: `screenshots/result/1/video.mp4` (30 s) + 900 frames, encoded with imageio-ffmpeg `-start_number 0 -i frame%08d.png`.
- Tests: use movie mode (`--write-movie`, `--fixed-fps 30`) for frame-accurate waits; headless runs too fast for timed fades.
- Synthetic `InputEventKey` used to call `_unhandled_input` must set BOTH `keycode` and `physical_keycode`; the `map` action is bound to physical Tab, so keycode-only events fail to match (pause/Escape worked because it uses keycode).
- **Pit softlock fix:** rooms can define `pits: [{rect, respawn}]`; Room builds an Area2D that deals 1 mask and teleports the player to the respawn ledge. Used in r4's 340px dash gap (respawn 900,1300). Test: `test/test_pit.gd` (masks 4→3, position returns to ledge).
- **Movie capture on Godot 4.7.2:** `--write-movie` combined with `--script` (SceneTree driver) writes fully transparent PNGs on this build; the movie maker reports 0 frames. Use a `.tscn` runner scene instead — e.g. `godot --path . --write-movie out/frame.png --fixed-fps 30 --quit-after N res://test/presentation_content.tscn`.
- **Movie capture quit:** never call `get_tree().quit()` from the driver; it corrupts the movie output. End the run with `--quit-after N` instead.
- **Movie capture + pause:** when the tree is paused (dialogue/map), the renderer stops producing new frames (`Engine.get_frames_drawn()` freezes) while `_process` keeps running, so the movie stretches unpredictably and the logic frame index drifts far from the PNG index. For deterministic proof shots, use `test/capture_moment.tscn -- --moment=<name>` (short per-moment runs, 60–200 frames); for a long demo, avoid pausing the tree in the driver.
- **Content capture moments:** `market`, `shop`, `lore`, `cavern`, `mask`, `boss`, `map`, `map_all`, `reward`, `passage`, `feather`, `pain`, `pain_mid`, `pain_deep`, `heart`, `charms`, `mobile`; README/STRUCTURE document the command.
- **Web export:** the Steam Godot build already ships export templates at `D:\SteamLibrary\steamapps\common\Godot Engine\editor_data\export_templates\4.7.2.stable\` (web_release.zip / web_nothreads_release.zip), so no template download is needed. `export_presets.cfg` has a Web preset with `variant/thread_support=false` (non-threaded WASM, works on GitHub Pages without COOP/COEP). Export: `godot --headless --path . --export-release "Web" docs/index.html`; exclude `docs/*` from the PCK.
- **Web secure context:** Godot 4 web refuses to start on plain HTTP over a LAN IP ("Secure Context" error). Test via `localhost`/`127.0.0.1` (secure context) or HTTPS; GitHub Pages is HTTPS. A local server must send `application/wasm` for the `.wasm` file.
- **Touch controls:** `scripts/touch_controls.gd` (CanvasLayer 12) maps `InputEventScreenTouch/Drag` to `Input.action_press/release`; tap buttons auto-release after 0.12 s, hold buttons (jump/focus) release on touch-up with a 0.08 s minimum, the joystick drives analog move + aim actions. Pause/map call `GameRoot.touch_toggle_pause/map` directly (action events do not reach `_unhandled_input`). `pointing/emulate_touch_from_mouse=true` makes mouse clicks count as touches; `Game.touch_mode` drives HUD hints. Tests: `test/test_touch.gd`.
- **Web CJK font:** Godot's `SystemFont` renders Chinese as tofu in the web export. The project bundles an OFL subset `assets/fonts/NotoSansSC-Medium-Subset.ttf` (592 glyphs, ~210 KB) and `Utils.font()` loads it first. Regeneration: instantiate Noto Sans SC `wght=500` with `fontTools.varLib.instancer`, extract every character in `scripts/*.gd` into a text file, then `python -m fontTools.subset ... --text-file=chars.txt --output-file=...`. Re-run whenever new Chinese strings are added.
- **Browser testing:** Playwright can load the exported build from `http://127.0.0.1` (secure context) with `hasTouch: true`; real touch events via CDP (`Input.dispatchTouchEvent`) drive the joystick/buttons, while mouse clicks do not operate the touch UI on the web. `emulate_touch_from_mouse` did not work in the web export, so GameRoot also starts/restarts on left mouse clicks; mobile start relies on real `InputEventScreenTouch`.
- **Moving platforms:** use `AnimatableBody2D` with `sync_to_physics = true` and move it in `_physics_process`; Godot's `CharacterBody2D.move_and_slide` then carries the player. Verified horizontal and vertical carry in `test/test_pain.gd` (dx < 5 px over ~50 frames).
- **Crumbling platforms:** `StaticBody2D` with a one-way `CollisionShape2D` + an 8 px `Area2D` detector on top; disable the shape deferred and re-enable after 2.8 s. In tests, advance `_process(0.7)` directly instead of relying on wall-clock frames.
- **Headless test timing:** run SceneTree tests with `--fixed-fps 30` (`godot --headless --path . --fixed-fps 30 --script res://test/test_extra.gd`). Without it, real-time tweens/timers and `dialogue_lock` behave differently and existing tests (test_systems/test_content) report false failures.
- **Special items (charms):** `Game.gain_item(id, title)` stores `special_items`, applies effects (`dash_charm`, `focus_scale`, `soul_gain_bonus`, `nail_bonus`) and emits `item_gained`. Room data key `specials`; pickups use `Kind.SPECIAL` (kind index 3 — mask shard stays index 2 for existing tests).
- **Path of Pain design:** r11 → r12 (horizontal) → r13 (vertical wall-jump chimney) → r14. The chimney needs `walls` starting below head height at the floor and a wide `ledge` floor under it; pits act as segment checkpoints (1 mask + teleport). The r13 wall-jump gap is 200 px (inner faces x 1240/1440).
